# 新生生活、运动与成长记录

## 离线手册

按身份和校区从 [知识入口](offline-guide.md) 汇总 Markdown：报到与周次、教务学工入口、奖助、图书馆、文献、办事路径。保留来源和日期；校车、宿舍、食堂价目缺失时给核实路径。

经验另标日期、样本、适用条件，不公开私密群聊和个人联系方式。当前包没有未经核实的美食榜或教师口碑。

## 长期记录

记录是事实，报告是派生结果。存到用户选择的包外目录，不把演示样本写入个人档案。

运动状态：`planned` 计划、`booked` 预约、`attended` 到场、`completed` 且 `evidence: user_confirmed` 为本人确认完成、`cancelled` 取消。签到不证明训练时长，预约不证明参加，没给分钟就不估算。

    python3 scripts/progress.py <记录.json> --start YYYY-MM-DD --end YYYY-MM-DD

输入见 [成长记录示例](../examples/progress-demo.json)。稳定 ID 去重；同 ID 内容冲突要确认。未记录日是缺失数据，不说没有运动，不推断健康或全校排名。

周报给完成次数、确认分钟、主要项目，再谈计划与实际差异、数据缺口、下周一个目标。不编造招募意图。分享时去掉私人地点、联系方式和固定轨迹。

## 场馆、活动与提醒

先核对校区、项目、日期、最新公告。没有实时工具可给入口和准备清单，不承诺余位或预约成功。

持续追踪由宿主定时工具在授权范围内执行；报告是否创建、执行时间与结果。无定时工具则给任务文案并写明尚未启用，不擅自创建系统 cron。
